# Features — Stage 1

## Campaign Management
- Natural Language Campaign Creation
- Campaign List & Status

## Business Discovery
- OSM + Overpass (seed)
- Optional Google Places API
- Basic deduplication

## Opportunity Detection
- No / Weak Website
- High Reviews + No Booking System
- Rule-based Opportunity Score

## Confidence System
- Verified / Likely / Unknown / Not Found

## Website Analysis
- Deterministic checks (SSL, viewport, booking fingerprint)
- LLM only for explanation

## AI Message Generation
- Template + Ollama
- Optional Groq (BYO key)
- Grounded in verified/likely facts only

## Outreach Safety
- Mandatory Human Approval
- ESP sending only
- Suppression list
- Unsubscribe handling
- Hard volume caps

## CRM
- Pipeline: New → Contacted → Follow-up → Interested → Won / Lost / Do Not Contact

## Explicitly Not in Stage 1
- Automatic sending
- WhatsApp
- Advanced reply intelligence
- Agency features
